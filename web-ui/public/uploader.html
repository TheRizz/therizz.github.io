Cyndaquil Uploader

A personal tool that publishes short animal-fact videos I create to my own YouTube, Instagram and TikTok accounts. It runs on my home server, has one user (me) and offers no public sign-up.

How it works

  1. Three times a day, my server picks a well-documented animal fact and writes a short narration with an AI model, followed by a fact-check pass.
  2. It builds a vertical 9:16 video from licensed stock footage (Pixabay), a synthetic voiceover and subtitles.
  3. It uploads the video to my accounts through each platform's official API: the YouTube Data API, the Instagram Graph API, and TikTok's Content Posting API.

TikTok integration

  • Login Kit (user.info.basic): I sign in once with TikTok to authorize posting to my own account.
  • Content Posting API (video.upload): each video is sent to my TikTok inbox as a draft that I review and post in the TikTok app.
  • Content Posting API (video.publish): once approved, videos are posted directly to my account with a caption, using a privacy level from TikTok's creator info, and every post is labeled as AI-generated.

Access tokens are stored only on my private server and are never shared.
