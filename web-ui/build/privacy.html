Privacy Policy

Last updated: October 21, 2026

This app is a personal tool operated by Ryan Martinez. It is used only to upload short videos that Ryan creates to Ryan's own YouTube, Instagram and TikTok accounts. It has no other users.

What data the app accesses

When Ryan signs in, the app receives an access token from the platform (Google/YouTube, Meta/Instagram or TikTok) that lets it upload videos to Ryan's account. It does not read, collect or store data about any other person.

How data is stored

Access tokens are stored only on Ryan's private server, in a file readable only by Ryan's user account. They are never sold, shared or sent to any third party other than the platform that issued them.

Google API Services

This app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. It uses the YouTube Data API only to upload videos to Ryan's own channel.

Revoking access

Access can be revoked at any time from the account's security settings (for Google: myaccount.google.com/permissions).
